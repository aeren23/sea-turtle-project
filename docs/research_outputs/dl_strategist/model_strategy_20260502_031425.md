# Deep Learning Architecture and Training Strategy for Sea Turtle Photo-ID

## Recommended Primary Approach
**Hybrid Approach** is recommended. This method balances the strengths of both classification and metric learning, enabling the model to utilize both the precision of direct classification and the flexibility of embedding-based retrieval. It provides a robust framework for identifying new individual turtles with limited data.

## Transfer Learning and Fine-Tuning Strategy
1. **Initial Phase**: Pre-train the CNN (ResNet-50 or EfficientNet-B0) on the ImageNet dataset.
2. **Fine-tuning**: Freeze some of the lower layers of the CNN while training the upper layers on the sea turtle dataset for improved feature extraction.
3. **Embedding Learning**: After classification training, add a metric learning layer to fine-tune the model to learn the embedding space.

## Training Hyperparameters
- **Learning Rate**: 1e-4 for fine-tuning;
- **Batch Size**: 16 - 32 (depending on GPU capacity);
- **Epochs**: 50 to 100, with early stopping based on validation performance.

## Evaluation Metrics
- **Accuracy**: Overall correctness of predictions.
- **Precision**: Proportion of true positive predictions.
- **Recall**: Sensitivity; ability to find all positive instances.
- **F1 Score**: Harmonic mean of precision and recall.
- **Mean Average Precision (mAP)**: Average precision across different thresholds; particularly useful in multi-class settings.

This structured strategy provides a systematic approach to tackle the identification and classification of individual sea turtles using deep learning, effectively leveraging limited data.
